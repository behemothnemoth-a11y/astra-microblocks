# Astra Chisel artwork

`astra-chisel-source.png` is the original artwork generated with the built-in imagegen tool
for the user's selected combination of Obsidian Edge and Stone Mason's grip.
The game uses `src/main/resources/assets/astra_microblocks/textures/item/astra_chisel.png`,
a 64×64 nearest-neighbor texture conversion preserving alpha. No external API key was used.
The item model retains Minecraft's handheld transforms and now references this texture.

Generation prompt:

> Create ONE standalone production game inventory sprite, not a board or mockup: the Astra Chisel for Minecraft. Transparent background with genuine alpha everywhere outside the tool. Center a single diagonal tool from lower left handle to upper right cutting tip, filling about 85% of square canvas. Crisp deliberate low-resolution pixel art on a 32 by 32 conceptual pixel grid, nearest-neighbor hard square pixels, small controlled palette, absolutely no antialiasing glow blur or shadows outside silhouette. Design combines OBSIDIAN EDGE blade and STONE MASON grip: short thick straight dark charcoal/black obsidian chisel blade, flat broad beveled cutting edge at upper right highlighted violet/amethyst, small violet facet along edge. Thick rugged brown leather-wrapped handle with obvious diagonal dark wrap bands, sturdy silver/iron ferrule joining blade to handle, squat square metal striking cap at lower left. Strong readable silhouette. A mason's wood/stone carving chisel, not a pickaxe, sword, knife or wand. Blade is straight and broad with a flat blunt-looking cutting tip, no pointed knife tip. Muted browns and dark gray, silver hardware, restrained bright violet bevel. Orthographic item sprite like Minecraft handheld item texture, no perspective environment, no text, no border, no inventory slot, no extra objects. Ensure all of the tool and generous transparent margin are inside frame. Square PNG with alpha.

The menu is drawn with native GUI primitives and controls, not generated artwork.
