# Delivery expectations

- Every update must include an installed, clearly named showroom schematic for the user to test, alongside individual library pieces. This is an explicit user preference from September 30, 2026, and supersedes the earlier preference for individual schematics only.
- Keep the expanding reusable archive; a showroom supplements it rather than replacing individual assets.
- Use ordinary Minecraft blocks for appropriate architecture and functional blocks, with microblocks for detail.
- Include representative new features and useful comparison/control areas. Supply smaller room or feature cutouts when the complete showroom is substantial.
- Verify exports, source placements, access routes and installed file hashes. Distinguish export checks from in-game visual, lighting and performance verification.
- For lighting, favor carved recessed inserts over exposed full-block sea-lantern fixtures. Document required mod version and actual emission policy.
